A. OBJECTIVES (Slide 4)
------------------------------------------------------------
- Build a web interface with client- and server-side validation for book data (title, author, ISBN).
- Implement RESTful CRUD operations: add, list, borrow, and return books.
- Track borrower patron records with 14-day loan periods and overdue detection.
- Maintain modular Java architecture (Book, Patron, Library, Controller, Service layers) with version control via Git.

------------------------------------------------------------
B. PROPOSED APPROACH & TECH STACK (Slides 7-8)
------------------------------------------------------------
Frontend:        HTML5, CSS, vanilla JavaScript (fetch API)
Backend:         Java 17, Spring Boot 3.2 (REST API)
Database:        In-memory ArrayList + file persistence (persistent DB planned for Phase 2)
Validation:      ISBN format check (10/13 digits, dashes allowed), duplicate ISBN detection,
                 required field checks (title, author), patron ID lookup
Testing:         Custom test runner (19 assertions: ISBN validation, CRUD, search, save/load)
Tooling:         Maven, Git, GitHub

Architecture / Flow:
  Client (Browser) -> API Routes (Spring REST) -> Validation Layer -> Service Layer -> Data Store -> JSON Response

Endpoints:
  GET  /api/books                — list all books
  GET  /api/books/available      — list available (not borrowed) books
  GET  /api/books/overdue        — list overdue books
  GET  /api/books/search?q=&by=  — search by title or author
  GET  /api/patrons              — list all patrons
  POST /api/books                — add a book (JSON: title, author, isbn)
  POST /api/patrons              — add a patron (JSON: id, name)
  POST /api/books/{isbn}/borrow?patronId= — borrow a book
  POST /api/books/{isbn}/return  — return a book

------------------------------------------------------------
C. DATA MODEL / SCHEMA (Slides 9-10)
------------------------------------------------------------
Entity: Book
  Fields:
    title     : String  (Required, non-empty, trimmed)
    author    : String  (Required, non-empty, trimmed)
    isbn      : String  (Required, 10 or 13 digits after removing dashes/spaces;
                         ISBN-10 may end in X; unique across all records)
    borrowed  : boolean (Default: false; toggled by borrow/return)
    borrowedBy: String  (Patron name; cleared on return)
    dueDate   : String  (yyyy-MM-dd, 14 days from borrow date; cleared on return)
    available : boolean (Derived: true when borrowed == false)

Entity: Patron
  Fields:
    id   : String (Required, unique, e.g. "P001")
    name : String (Required, non-empty)

Validation Rules:
  - ISBN must match 10-digit or 13-digit format (dashes and spaces stripped before check)
  - ISBN must not already exist (duplicate rejection)
  - Title and author must be non-empty after trimming
  - Borrow: fails if book not found, already borrowed, or patron not found
  - Return: fails if book not found or not currently borrowed
  - Patron ID must be unique

CSV Import Format (data/books.csv):
  title,author,isbn
  Pride and Prejudice,Jane Austen,9780141439518
  ...

File Persistence Format (data/library_state.txt):
  PATRON,P001,Alice Smith
  BOOK,Dune,Frank Herbert,9780441172719,true,Alice Smith,2025-10-05
  ...
